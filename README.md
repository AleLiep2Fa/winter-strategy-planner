# Winter Strategy Planner

A small browser-based planning tool for the Pork and Garlic Ice Cream Winter strategy.

It starts with the Year 1 assumptions already chosen by the team:

- Premise D
- Machine 1
- 2 tonnes of milk
- 40,000 ice-cream sales target
- EUR 2 selling price

Use the calculator to adjust costs, sales, production, cash, and interest assumptions. It reports the projected profit or loss, break-even point, required up-front cash, recommended planning loan, and the most important capacity or profitability constraint.

## Publish with GitHub and Vercel

Push this folder to a GitHub repository, then import that repository in Vercel. Configure Vercel as a static site with `dist` as the output directory.
